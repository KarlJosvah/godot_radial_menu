# Radial Menu v1.0.0

Initial release of the **Radial Menu** addon for Godot 4.

## Features

- **Procedural 2D Rendering**: Dynamic rendering of radial menu slices, dividing lines, center cutouts, and icon textures using Godot's CanvasItem drawing APIs.
- **Dual Input Support**:
  - Full analog gamepad navigation (configurable for Left Stick, Right Stick, or Any Stick) with built-in deadzones and angular sector calculation.
  - Mouse pointer navigation with support for captured virtual mouse coordinates.
- **Component-Based Architecture**:
  - `Input`: Handles mouse and gamepad directional calculation.
  - `Render`: Handles canvas drawing of backgrounds, dividers, active slice highlights, and option textures.
  - `Interact`: Controls open/close states, input capturing, and smooth scale tween animations.
  - `Config`: Manages radius sizing relative to viewport dimensions and configuration warnings.
  - `Linked`: Coordinates cascading sub-wheel menus.
- **Linked Wheels (Cascading Sub-menus)**:
  - Support for multi-tiered menus where hovering over an option automatically opens a corresponding child radial menu.
- **Lifecycle Signals**:
  - `on_wheel_opened()`: Emitted when the radial menu finishes opening.
  - `on_selection_change(selected_index: int)`: Emitted whenever the highlighted option index changes.
  - `on_wheel_closed(selected_index: int)`: Emitted when the menu closes, providing the selected index.
- **Editor Tool Support**: Real-time rendering and property validation directly in the Godot 2D editor viewport.
