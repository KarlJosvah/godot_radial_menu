# Radial Menu v1.0.1

This maintenance release extracts the radial menu into a completely self-contained Godot Editor addon, improves modularity, and fixes node instantiation issues in external projects.

## What's Changed

- **Self-Contained Addon Package**:
  - Migrated the codebase to `addons/radial_menu/` with a formal `plugin.cfg` and `EditorPlugin` registration script.
  - Added custom node registration for `RadialMenu` in the "Create New Node" dialog with an editor icon.

- **Standalone Option Resource**:
  - Introduced `RadialMenuOption` (`res://addons/radial_menu/radial_menu_option.gd`) as a built-in subclass of `AtlasTexture`.
  - Removed reliance on external class definitions so the addon can be dropped into any Godot project without missing class or parser errors.

- **Automated Child Component Instantiation**:
  - Added `_ensure_child_nodes()` to `RadialMenu` to programmatically spawn and configure the required helper nodes (`Input`, `Render`, `Interact`, `Config`, `Linked`) when added directly to scenes via the editor.

- **Demo Scene Dogfooding**:
  - Migrated Demo 1 (`01/`) and Demo 2 (`02/`) to consume the addon directly from `res://addons/radial_menu/`, establishing the addon as the single source of truth.

- **CI/CD Pipeline Improvements**:
  - Added automated GitHub Actions release workflow that tags and packages releases when changes are pushed to `addons/**`.
  - Added `workflow_dispatch` manual trigger in GitHub Actions.
  - Added automatic attachment of matching release note files from `release-notes/` into GitHub Releases.
